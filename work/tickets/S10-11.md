# S10-11 Release launch environment: compact core affinity through the BOINC wrapper

Sprint 10. Depth: light. No card access (the lead runs card jobs). Host load cap: 4 cores. Never write to
`C:/ProgramData/BOINC`.

## Why
The release now uses the S10-10 batched vector star setup (`config/release.env`). Its card speedup (core-small
52.1 -> 41.5 s, real-steps 251.5 -> 181.9 s) was measured with compact core affinity: each core's 4 threads pinned
together via `GOMP_CPU_AFFINITY="1 2 ... 240"`, `OMP_PROC_BIND=TRUE`, checked by `.work/S10-10/scripts/
s10-df-batch-launch.sh` (`DF_BATCH_AFFINITY=1`, sysfs sibling check). The packaged release launched without those
settings ran core-small 57.3 s and real-steps 283.4 s (no batch gain), identical likelihoods. A BOINC task must get
the same environment.
