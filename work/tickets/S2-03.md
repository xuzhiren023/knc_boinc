# S2-03 app_info.xml and the project-directory package

Sprint 2. Depth: light. Network: yes (read the project's public app pages only). Depends on S2-02.

## Do
1. Find what MilkyWay@home currently distributes for N-body (app name, version numbers, plan classes, command-line
   and file names of its workunits) from its public pages (apps.php and similar); cite the URLs and date.
2. `packaging/make_package.sh` builds `dist/milkyway_package/`: everything that goes into the BOINC project directory
   (`knc_wrapper.exe`, its DLLs, `knc_wrapper.cfg.example`, the card package files, later the graphics app) and an
   `app_info.xml` that declares one app version using **1 host CPU** (`avg_ncpus` 1) with the wrapper as main
   program, matching the app name the server uses. Explain each field choice.
3. A checker script that validates app_info.xml against the files present (names, main_program, file refs).

## Acceptance
- The package builds from the repo; the checker passes; `docs/packaging.md` explains the anonymous-platform setup and
  its risks (the server may refuse or the validator may reject results; that is the owner's call to try).
