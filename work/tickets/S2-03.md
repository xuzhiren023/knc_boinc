Sprint 2. Depth: light. Network: yes (read the project's public app pages only). Depends on S2-02.

## Do

   and file names of its workunits) from its public pages (apps.php and similar); cite the URLs and date.
2. `packaging/make_package.sh` builds `dist/milkyway_package/`: everything that goes into the BOINC project directory

   `app_info.xml` that declares one app version using **1 host CPU** (`avg_ncpus` 1) with the wrapper as main

  collects host DLL imports transitively using the supplied objdump, copies
