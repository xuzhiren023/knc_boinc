# S11-01 Graphics through BOINC Manager's Show graphics button and the BOINC screensaver

Sprint 11 (runs in parallel with Sprint 10; different files). Depth: light. No card access. Never write to
`C:/ProgramData/BOINC` and never start or stop the owner's BOINC client.

## Why
Owner 2026-11-17: connect our program with BOINC Manager, so the Manager's "Show graphics" button (and the BOINC
screensaver) opens our live view of the card's simulation. The package already declares `knc_nbody_graphics.exe` as
`graphics_app` (packaging/make_package.sh) and the wrapper relays card snapshots to BOINC graphics shared memory
(Sprint 3), but this has never been checked against how the BOINC Manager and screensaver actually start a graphics
app on Windows.
