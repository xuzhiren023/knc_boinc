# S11-01 Graphics through BOINC Manager's Show graphics button and the BOINC screensaver

Sprint 11 (runs in parallel with Sprint 10; different files). Depth: light. No card access. Never write to
`C:/ProgramData/BOINC` and never start or stop the owner's BOINC client.

## Why
Owner 2026-11-17: connect our program with BOINC Manager, so the Manager's "Show graphics" button (and the BOINC
screensaver) opens our live view of the card's simulation. The package already declares `knc_nbody_graphics.exe` as
`graphics_app` (packaging/make_package.sh) and the wrapper relays card snapshots to BOINC graphics shared memory
(Sprint 3), but this has never been checked against how the BOINC Manager and screensaver actually start a graphics
app on Windows.

## Do
1. From the pinned BOINC client sources (`third_party/boinc`, client 8.2.8): how the Manager's Show graphics request
   and the screensaver (`boincscr`/screensaver mode) find and launch the graphics app (command-line arguments such as
   `--fullscreen`, working directory = slot directory, the shared-memory segment name, which files it expects in the
   slot, what makes the button enabled or greyed out: graphics_app in app_info, `app_version` flags, the task
   running state). Cite file and line.
2. Check `src/knc_nbody_graphics.cpp` and the wrapper against that: window mode vs `--fullscreen`, finding the
   segment from the slot, behaviour when no snapshot exists yet, exit when the task ends or the screensaver stops.
   Fix what does not match (wrapper/graphics/package only).
3. Test with the fake BOINC client harness (tests/wrapper.sh, tests/knc_client_scenarios.h): a scenario that starts
   the graphics app the way the Manager does and the way the screensaver does, with a fake card producing snapshots;
   capture a screenshot of each mode into `docs/img/`.
4. An owner walkthrough section in `docs/TRY-IT.md`: after installing the package and resuming a task, click Show
   graphics in BOINC Manager (Tasks tab), and how to select the BOINC screensaver in Windows; what the owner should
   see; how to check the button is enabled.
