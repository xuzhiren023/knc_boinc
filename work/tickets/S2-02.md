# S2-02 knc_wrapper: one BOINC task that runs N-body on the card

Sprint 2. Depth: deep. Depends on S2-01 (merged) and Sprint 1. Decisions D5, D6.

## Do
1. `knc_wrapper.exe` (BOINC API, variant from S2-01), reading `knc_wrapper.cfg` from its directory or the slot: card
   host, user, ssh key path, ssh/scp paths (default Windows OpenSSH), remote base dir (default `/tmp/knc-boinc`),
   `OMP_NUM_THREADS` (default 240), poll interval (default 10 s), connect timeout, retry limit.
2. Task flow: `boinc_init_options` with process control handled by the wrapper itself; resolve logical file names;
   make a unique remote dir; stage the card package (binary + runtime .so) and inputs; start the card app detached
   (`nohup`, PID file, stdout/stderr files, `OMP_NUM_THREADS`); poll progress file and PID; report
   `boinc_fraction_done`; on finish copy outputs back to the resolved names, check the exit status, clean the remote
   dir, `boinc_finish`.
3. Control: suspend -> `kill -STOP`, resume -> `kill -CONT` on the card PID; quit -> copy the card checkpoint into the
   slot, kill the card process, exit so the client restarts later; restart with a slot checkpoint uploads it and
   resumes; abort -> `kill -KILL`, clean up. Card unreachable -> bounded retries, then `boinc_temporary_exit` with a
   clear message.
4. The small card-app patch for progress and checkpoint files (D6) if upstream's standalone build lacks them; keep it
   minimal under `patches/`.
5. Make the Cygwin guards in `patches/boinc/` consistent (`__CYGWIN__`; S2-01 review).
6. `--fake-card DIR` test mode: ssh/scp replaced by local commands that run the x86 build in DIR, so every flow above
   is testable on the laptop without the card. Use S2-01's fake client to drive suspend/resume/quit/abort in tests.

## Acceptance
- Tests (fake card + fake client) cover: normal finish with outputs, suspend/resume, quit then restart from checkpoint,
  abort, card unreachable. Each fails before the feature exists.
- `docs/wrapper.md`: config keys, flow, what each BOINC signal does on the card, and what is not proven without the
  real client and card.
