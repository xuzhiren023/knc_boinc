# S10-09 Relaxed 8-lane star-setup integrand (owner-approved experiment)

Sprint 10. Depth: deep. No card access (the lead runs card jobs). Host load cap: 4 cores (`make -j2`,
`OMP_NUM_THREADS=4`).

## Why
Owner 2026-11-17: try the relaxed vector path. Real tasks spend ~97% of card time in star setup (real-steps: setup
234-241 s of 244 s; full 117676: 1,319 s of 1,673 s); the node evaluation of `fun` is ~34 s of 48 s on core-small.
S10-05 measured that GCC-KNC's 1-ULP libknc_vmath (used one lane at a time) changed 0 of 4,000 and 0 of 110,000
generated bodies and left the core-small likelihood bit-identical on host and card. S10-05's `DF_SPECIAL=1` removed
the function pointer and type switch (block 1); `-fopt-info-vec-missed` says the node loop is still blocked by the
crlibm calls (log_rn, atan_rn, exp_rn, pow_rn) and the incomplete-gamma series (data-dependent iteration count).

## Do
1. `DF_VECTOR8=1` (own Performance patch, off by default, on top of `DF_SPECIAL=1`): evaluate 8 quadrature nodes per
   IMCI vector for the Plummer + cored models: potential/density samples, both finite-difference stencils and the
   integrand, with libknc_vmath for log/exp/pow and atan (use what the library offers, e.g. atan2(x,1), or a hand
   IMCI atan built from it), and the incomplete-gamma series as a masked vector loop where each lane stops at its own
   convergence test (same test as the scalar code). Keep the per-node expression order of the scalar code where you
   can; the quadrature sum stays serial in the original order. Let GCC-KNC vectorize where it can
   (`-mveclibabi=knc -fno-math-errno`), hand IMCI intrinsics for the rest (compiler-first rule: list what the
   compiler could not do as compiler items with repros).
2. `DF_VECTOR8_GUARD=1` (optional second option): for each accept/reject and max-finder comparison, if the fast
   decision is within an empirical margin of the threshold (choose it from measured fast-vs-exact differences, with
   a large safety factor, and say how), redo that body's velocity exactly with the saved dSFMT state (S8-05's
   mechanism). Report how often it triggers.
3. Measure, against the exact release: differing bodies (any byte) and the first RNG divergence for core-small,
   real-steps and the full 117676 generation (one full run per variant), and the core-small and real-steps
   likelihood difference. Host generation time at 4 threads (state it).
4. Card binaries with the release options plus `DF_SPECIAL=1 DF_VECTOR8=1` (and the guard variant), knc_lint, a
   window script for this repo's `tools/card_run` with `--transfer tcp-large` (core-small, real-steps), with
   predictions recorded before the card run.
