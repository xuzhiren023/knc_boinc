# S9-05 Faster mixed-dwarf body generation: derivative reuse, then a certified vector integrand (bodies identical)

Sprint 9. Depth: deep. No card access. Laptop load light (owner): `make -j2`; the full 117676 generation (about
18 min on 12 threads) at most once, at the end, for the final build only.

## Why
Card, core-small (real 117676 Lua and arguments, 4,000 bodies): ~60-62 s, almost all in body generation (PHASE
setup 59-62 s); PGO gave -4%. Generation is dominated by `fun` (`nbody_mixeddwarf.c`) inside `gauss_quad`, already
parallel over quadrature nodes (S8-03, `PARALLEL_QUAD=1`). Two known gains:
- Derivative reuse: `first_derivative` and `second_derivative` sample the same function at x-2h, x-h, x+h, x+2h, so
  each node makes 20 potential + 9 density calls where 10 + 5 distinct values suffice. GCC-KNC already removes them
  once the samplers are pure (`.work/S8-09/probes/s8_df_reuse.c`: 29 vs 15 calls), but the samplers are not pure:
  `set_model_params` initializes lazily when `p0 == 0`. Make that initialization eager, once, before sampling (or
  hoist it to the caller), then mark the samplers pure; or reuse the samples by hand. Pick the smaller patch.
- Vector integrand: evaluate potential/density for 8 nodes at once (libknc_vmath, within 1 ULP, `-mveclibabi=knc`,
  `-fno-math-errno`), carry a rigorous per-node error bound through the finite differences into S8-05's guarded
  decisions (`patches/nbody-fast-df.patch` on branch ticket/S8-05: exact replay of a body's velocity on any uncertain
  decision). Keep it only if bodies stay byte-identical and the fallback rate leaves a gain.

## Do
1. Derivative reuse (`DF_REUSE=1`, own performance patch, off by default). Bodies byte-identical for core-small;
   likelihood bit-identical; x86 generation time before/after at 12 threads (one run each).
2. Certified vector integrand (`DF_VECTOR=1`, own patch, needs 1): error-bound argument written down, fallback counts
   and generation time for core-small; if the bound forces fallback on most bodies, stop and report the numbers.
3. Card binaries with the S9-01 base options (`TREE_VARIANT=2 PARALLEL_QUAD=1 STATIC_INTEGRATE=1 PHASE_TIMERS=1
   VECTOR_GRAVITY=0 FORCE_CHUNK=4`, O2) plus `DF_REUSE=1` (`build/s9/card-dfreuse/`) and, if kept, `DF_VECTOR=1`
   (`build/s9/card-dfvec/`); knc_lint; card commands for core-small with this repo's `tools/card_run`.
4. Final build only: full 117676 generation bodies byte-identical to the S7-02 reference (S8-05/S8-09 have the
   extractor and hashes).

## Accept
- Byte-identical bodies, likelihood compare, timings, fallback counts, binaries, commands and the Effort line.
