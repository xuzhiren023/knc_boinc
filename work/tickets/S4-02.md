Sprint 4. Depth: light. Depends on everything else and on the lead's end-to-end run (S4-01).

install from boinc.berkeley.edu), build or use the package, card config file, an **offline test** first (standalone

MilkyWay@home and returning results is the owner's decision and what the risks are.
