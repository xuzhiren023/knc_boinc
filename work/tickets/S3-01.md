# S3-01 Card snapshots and wrapper relay into BOINC graphics shared memory

Sprint 3. Depth: standard. Depends on S2-04 and S3-02 (merged). Uses `src/knc_graphics_format.h` from S3-02.

## Do
1. Card app (extend the existing minimal patch under `patches/`): with `--snapshot-interval S` (off by default), write
   a subsampled body snapshot in the S3-02 format every S seconds, to a temp name then rename. Measure cost on x86:
   under 1% of run time at the wrapper's default interval (5 s).
2. Wrapper: fetch the snapshot with each poll (rate-limited), publish it in BOINC graphics shared memory in the S3-02
   layout with sequence number and status (running/suspended/finished/waiting for card), using the BOINC API call the
   S2-01 doc identified.
3. `docs/graphics-shmem.md`: the end-to-end path card -> wrapper -> graphics app.
4. Visual polish of `knc_nbody_graphics` (S3-02 review: the bodies show as a tiny clump in the centre): frame the
   camera on the bodies (robust extent, e.g. 98th-percentile radius about the centre of mass, smoothed over time so it
   does not jump), point size and brightness that scale with window size and body count, a faint reference (Galactic
   centre marker and disc plane grid or similar) so the stream's motion reads, and colour by type. Use a demo snapshot
   from a run evolved long enough to show tidal stripping (S1-02's `large` or `medium` final state) for the screenshot.

## Acceptance
- Fake-card test: the wrapper publishes snapshots whose contents match the x86 app's file; sequence advances;
  status follows suspend/resume. The graphics app shows the live fake-card run, and the new demo screenshot
  (`docs/img/`) shows a framed, readable stream (the lead looks at it).

## Engineer report

Implemented in the S3-01 worktree. No commit/index/branch writes, downloads,
installs, card access, or writes to gcc_knc. Builds used bash and the supplied
Cygwin/GCC-KNC tools with TMPDIR, TMP and TEMP exported to this worktree's
build/tmp before compilation.

Changes:

- Extended the existing minimal nbody-wrapper-files.patch. The standalone CPU
  app accepts --snapshot-interval S, disabled by default; rejects negative and
  nonfinite intervals; samples at safe completed steps using monotonic wall
  time. It selects at most 4096 evenly spaced body indices, preserves position
  and type, zeroes unused wire storage, records simulation time/step/progress,
  and publishes snapshot.tmp by close then rename to snapshot. Completion
  forces the final snapshot. The shared S3-02 header is used in both builds.
  Snapshot failure does not change science/checkpoint behavior.
- Wrapper configuration snapshot_interval defaults to 5 seconds. The wrapper
  supplies that option, probes snapshot presence with polls, rate-limits
  downloads, forces a final fetch, validates the exact fixed wire format, and
  retains the last good frame. Downloads use a separate nonfatal path.
- The actual BOINC boinc_graphics_make_shmem API creates the per-slot mapping.
  Publication uses atomic odd/even sequence stores and full barriers, with
  running/suspended/finished/waiting status. Heartbeats continue while
  suspended and while waiting for child transport commands. Connection
  failures publish waiting. Added the option to the example configuration.
- Graphics use a smoothed centroid and 98th-percentile projected radius,
  orthographic framing, viewport/body-count point sizing and brightness, gold
  light matter / blue dark matter, a faint Galactic disc grid and centre mark.
  Suspended data keep the frozen body frame. The demo is the actual full
  medium run (1024 bodies, seed 670828913, 3.945 Gyr, four threads), rather than
  the former 0.004-Gyr fixture. Screenshot:
  docs/img/knc-nbody-graphics.png. Inspected the actual captured window PNG;
  it shows an extended curved tidal stream. Medium contains light bodies;
  the screenshot therefore correctly shows gold. Demo step remains zero
  because upstream's text body output does not contain a step count.
- Added docs/graphics-shmem.md, updated graphics and patch documentation,
  extended the existing fake-client acceptance with a live graphics scenario,
  and added tests/snapshot_cost.py. The standard wrapper test now includes
  graphics. Its client executable path also works under Cygwin bash.
- Final card binary/runtimes: dist/card/. Native smoke run script:
  scripts/card-snapshot-run.sh (usage and staging in graphics-shmem.md).
  The complete anonymous-platform package is in dist/milkyway_package/.
