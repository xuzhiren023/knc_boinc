# S3-02 knc_nbody_graphics: screensaver and graphics window

Sprint 3. Depth: standard. Depends on S3-01.

## Do
1. `knc_nbody_graphics.exe` (Win32 + legacy OpenGL via opengl32, Cygwin build with w32api; no GLFW): opens the graphics
   shared memory as a BOINC graphics app does (name from the BOINC graphics API) and draws the bodies as soft points
   in 3D, slow auto-rotation, colour by body type, a small text overlay (project, progress, "running on Xeon Phi
   KNC, 240 threads", status). Windowed by default; `--fullscreen` for the BOINC screensaver (follow BOINC's graphics
   app conventions for that flag and for exiting).
2. No shared memory yet or task suspended: show a calm idle scene with the status, never crash.
3. `--demo FILE` reads a snapshot file directly (for tests and for the guide's first look).
4. Add it to the package and app_info.xml as the graphics app.

## Acceptance
- Builds with `make -C mk graphics`; runs `--demo` on the laptop; the report includes a screenshot (PNG in `docs/img/`).
- Survives: missing shmem, stale sequence, zero bodies, window resize.
