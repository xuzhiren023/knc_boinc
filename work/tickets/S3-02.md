# S3-02 Graphics formats and knc_nbody_graphics (screensaver and window)

Sprint 3. Depth: standard. Runs in parallel with S2-04; S3-01 (producer side) builds on this.

## Do
1. `src/knc_graphics_format.h` (C, shared by card app patch, wrapper and graphics app): the snapshot file format the
   card writes (magic, version, body count <= 20,000, float32 x/y/z, type tag dark/light, sim time, step, fraction
   done) and the graphics shared-memory layout the wrapper publishes (versioned header with sequence number and
   status running/suspended/finished/waiting plus the snapshot). Fixed-size, little-endian, no pointers. Unit-test
   the size and offsets on x86 and with the card compiler (static asserts in a card object).
2. `knc_nbody_graphics.exe` (Win32 + legacy OpenGL via opengl32, Cygwin build with w32api; no GLFW): opens the BOINC
   graphics shared memory the way a BOINC graphics app does (see docs/boinc-api-on-cygwin.md), draws the bodies as
   soft points in 3D with slow auto-rotation, colour by type, a text overlay (project, progress, "Xeon Phi KNC, 240
   threads", status). Windowed by default; `--fullscreen` for the BOINC screensaver per BOINC's graphics-app
   conventions. No shared memory yet, suspended or stale: a calm idle scene with the status, never a crash.
3. `--demo FILE` reads a snapshot file directly; add `tools/make_demo_snapshot.py` that writes one from an x86 N-body
   run's output (positions of the final state from upstream's output file).
4. `make -C mk graphics`; add the graphics app to the package and app_info.xml (`<file_ref>` with `<graphics_app/>`
   per BOINC's anonymous-platform docs in the pinned source or client code).

## Acceptance
- Format tests pass on both compilers; the graphics app runs `--demo` on the laptop; a PNG screenshot in `docs/img/`
  (capture it from the window); survives missing shmem, stale sequence, zero bodies, window resize (tests or scripted
  checks); package checker passes with the graphics app.

## Engineer report

Implemented S3-02 in this worktree; no commits, Git writes, installs, downloads,
card connections or changes to the toolchain repository.

- Added `src/knc_graphics_format.h`, a shared C wire contract: little-endian
  fixed-size 320048-byte snapshots and 320080-byte graphics mappings, <=20000
  float32 Cartesian bodies, dark/light tags, simulation time, step and fraction,
  version/size/magic, status and aligned sequence. Documented the single-writer
  odd/even publication barriers, heartbeat and five-second stale threshold.
- Added Win32/Cygwin `knc_nbody_graphics.exe` using w32api, GDI font display lists
  and system `opengl32` legacy GL. It attaches through the real BOINC graphics
  API with slot-derived `knc_nbody` naming, retries missing mappings, validates
  snapshots, and shows calm idle scenes for missing/invalid, suspended, waiting
  or stale data. Includes type colours, soft camera-facing points, rotation,
  project/progress/hardware/status overlay, resize, default window mode and
  `--fullscreen` with screensaver input exit behavior.
- Added `--demo FILE` and `tools/make_demo_snapshot.py`. The converter reads the
  actual pinned upstream final-body output (both simple/full variants), not
  histograms. Time/step are explicit optional inputs because the body output
  lacks them. Added optional `--screenshot BMP` to capture the rendered window
  framebuffer before presentation. Desktop/GDI capture proved unreliable under
  this compositor; the delivered screenshot uses the actual window's OpenGL
  framebuffer, not a separately rendered image.
- Added `make -C mk graphics`, acceptance tests, package executable/dependency
  discovery, manifest markers, checker enforcement and graphics documentation.
  Updated packaging documentation. The package has 12 files plus app_info.xml.
